# customer-churn-prediction
Customer Churn Prediction System using Machine Learning (Random Forest) and Streamlit to predict whether a bank customer is likely to leave the bank.

### Key Features

* 🏦 Predicts whether a customer will stay or leave the bank.
* 🤖 Built using the **Random Forest Machine Learning Algorithm**.
* 📊 Interactive and user-friendly **Streamlit** web interface.
* 📝 Accepts customer details such as credit score, age, balance, salary, tenure, and more.
* 📈 Displays churn prediction with probability and risk level.
* 💡 Provides recommendations based on prediction results.
* 🎨 Modern dashboard with responsive design and attractive UI.
* ⚡ Fast and real-time prediction using a trained ML model.

### Technologies Used

* Python
* Streamlit
* Scikit-learn
* NumPy
* Pandas
* Pickle

### Project Structure

* `app.py` – Main Streamlit application
* `Churn_Modelling.csv` – Dataset
* `random_forest_churn_model.pkl` – Trained Random Forest model
* `scaler.pkl` – Data preprocessing scaler

### Applications

* Customer retention analysis
* Banking analytics
* Business decision support
* Churn risk assessment
